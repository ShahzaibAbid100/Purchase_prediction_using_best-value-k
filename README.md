Project Objective

The objective is to predict customer purchase decisions based on:

- Age
- Estimated Salary

Target:

- 0 = Not Purchased
- 1 = Purchased

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab 

 Machine Learning Workflow

1. Load the dataset
2. Explore and clean the data
3. Select features and target
4. Split training and testing data
5. Apply StandardScaler
6. Test different K values
7. Use 5-fold cross-validation
8. Find the best K value
9. Train the final KNN model
10. Make predictions
11. Evaluate using accuracy
12. Analyze confusion matrix
13. Check precision, recall and F1-score
